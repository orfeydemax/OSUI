# CHANGELOG — Реестр завершённых изменений

> **Назначение:** Единый компактный файл истории всех CHG. ИИ читает ТОЛЬКО этот файл при старте сессии.
> Полные change_card.yaml остаются в `docs/Done/{CHG-ID}/` как архив для людей.
>
> **Правило:** При каждом `/release` → добавить запись в начало текущего месяца.

---

## Справочник форматирования

Каждая запись CHANGELOG содержит ровно 4 строки:
```
### {CHG-ID} | {Track} | ✅ Done | {Дата}
**Тема:** {Краткое описание в 1 строку}
**Файлы:** {Затронутые модули через запятую}
**Результат:** {Что изменилось для пользователя/системы}
```
