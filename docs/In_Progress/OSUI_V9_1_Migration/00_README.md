# OSUI V9.1 Antigravity OODA Pack

Этот пакет нужен для **постепенного внедрения OSUI V9.1 hardening** в существующий проект на Antigravity без сноса текущей системы.

## Принцип
Мы внедряем изменения не одним жирным махом, а циклами **OODA**:

- **Observe** — понять текущую реальность репозитория и найти разрывы.
- **Orient** — собрать рабочую память проекта и baseline живой системы.
- **Decide** — зацементировать gate-логику, маршрутизацию и запреты.
- **Act** — переписать workflows, release-контур и scripts.
- Затем цикл повторяется уже на пилотном change.

## Как использовать
### Вариант 1 — надёжный
Передавай Antigravity **по одному файлу за раз**.  
Не переходи к следующей фазе, пока предыдущая не дала:
- список изменённых и созданных файлов;
- diff-логику;
- открытые хвосты;
- локальный acceptance report.

### Вариант 2 — одним пакетом
Можно загрузить весь пакет сразу, но потребовать жёсткий порядок:

```text
Работай строго по файлам от 01 до 08.
Не перепрыгивай фазы.
После каждой фазы выдай:
1. что создал,
2. что обновил,
3. что осталось незакрытым,
4. почему следующий шаг теперь допустим.
```

## Главный запрет
Запрещено:
- переписывать OSUI с нуля;
- выкидывать текущую структуру `docs/` и `.agent/`;
- заменять OSUI на другой стандарт;
- объявлять migration complete, если нет хотя бы одного реально рабочего verify path;
- считать `docs/CHANGELOG.md` полной памятью живой системы.

## Главный успех
Успех — это когда:
- у репозитория есть repo-local truth для baseline живого продукта;
- `/enhance` больше не стартует вслепую;
- `/verify` не врёт про сохранность старого поведения;
- `/release` обновляет product memory, а не только release memory;
- harness имеет хотя бы минимальный исполнимый набор capability.
