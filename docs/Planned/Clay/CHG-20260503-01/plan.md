# Plan: CHG-20260503-01 — Hero Redesign Victor DivePro

**Stage:** Plan  
**Branch:** `chg/CHG-20260503-01`  
**Owner:** max  
**Дата:** 2026-05-03

---

## 1. Проблема (из Clay)

Первый экран сайта Victor DivePro стильный, но не продающий.  
За 3–5 секунд пользователь **не понимает** ключевого оффера:
- что это дайвинг в Нячанге
- что можно без опыта
- что забирают из отеля
- что инструктор рядом под водой

Текущий H1 («ДАЙВИНГ / БЕЗ / СУЕТЫ» в 3 строки) занимает пол-экрана.  
CTA-кнопки расположены низко. Иллюстрации декоративные, не объясняют маршрут.

---

## 2. Цель изменения

Редизайн hero-секции так, чтобы:
1. За 3 сек считывался оффер (дайвинг в Нячанге, без опыта, русский инструктор, трансфер)
2. CTA «Узнать свободные даты» был виден без прокрутки
3. Правая колонка объясняла маршрут: отель → инструктаж → погружение → обратно
4. На мобиле работал sticky bottom bar с CTA

---

## 3. Scope изменений

| Файл | Что меняем |
|------|-----------|
| `site/src/pages/HomePage.jsx` | Hero section (разметка, текст, структура) |
| `site/src/components/Navbar.jsx` | Логотип + текст, меню, sticky bottom bar |
| `site/src/index.css` | Стили hero--new, route-cards, trust-items, navbar overrides |

**Не трогаем:**
- Все остальные страницы (`BeginnerPage`, `SnorkelingPage`, etc.)
- Footer, MobileBar, FaqSection, CtaFinal
- Маршруты (routes) — без изменений
- CSS переменные и design tokens

---

## 4. Задачи (ordered)

### T1. Hero layout (2 колонки)
- Левая 45%: бейдж + H1 + subtitle + CTA + trust items
- Правая 55%: 4 route cards (маршрут клиента)
- min-height: 760–860px
- На мобиле: одна колонка

### T2. Типографика H1
- Размер: clamp(44px, 6vw, 96px) — уменьшить на ~35% от текущего
- 2 строки: «Дайвинг / без суеты»
- text-transform: uppercase

### T3. CTA-кнопки
- «Узнать свободные даты» (primary, dark navy)
- «Написать инструктору» (outline)
- Подпись: «Ответим в WhatsApp или Telegram...»

### T4. Trust items (блок доверия)
- 4 пункта с иконками ✓
- «Можно без опыта», «Инструктор рядом под водой», «Трансфер из отеля», «Снаряжение включено»

### T5. Route cards справа
- 4 карточки: 1. Забираем из отеля, 2. Инструктаж, 3. Погружение, 4. Возвращаем обратно
- Каскадное смещение (2-я и 4-я +30px вниз)

### T6. Navbar
- Floating pill: белый фон, border-radius 24px, высота 72px
- Логотип + «VICTOR DIVEPRO» слева
- Меню по центру (5 пунктов)
- Кнопка «Написать» справа

### T7. «Как проходит поездка»
- 5 шагов линейным списком (уже есть в `#how-it-works`)
- Обновлённый заголовок и структура

### T8. Мобильная версия
- Одна колонка в hero
- Sticky bottom bar: «Узнать даты» + «Написать»
- Navbar компактный 68px

---

## 5. Критерии готовности

- [ ] Бейдж виден в первом экране
- [ ] H1 в 2 строки, не давит
- [ ] CTA «Узнать свободные даты» виден без прокрутки (desktop и mobile)
- [ ] 4 route cards читаются слева направо/сверху вниз
- [ ] Trust items: 4 пункта с чекмарками
- [ ] Sticky bottom bar на мобиле
- [ ] Navbar: floating pill, логотип + текст, меню 5 пунктов
- [ ] Нет JS-ошибок в консоли
- [ ] Адаптив: 375px mobile без горизонтального скролла

---

## 6. Риски

| Риск | Вероятность | Митигация |
|------|------------|-----------|
| Глобальный h1 перебивает hero-new размер | Высокая | Добавить специфический селектор `.hero--new h1` |
| Sticky bottom bar дублирует MobileBar | Средняя | Скрыть на мобиле один из них |
| Якорные ссылки в меню (`/#section`) не работают при SPA-навигации | Средняя | Использовать `href="#section"` без ведущего `/` |

## 7. Экономика изменения

- **Трек:** Core (низкий риск, один компонент-слой)
- **Затраты:** 1–2 часа верстки
- **Ценность:** прямое влияние на конверсию первого экрана
- **Откат:** `git revert` или переключение на main
