# Заметка о фрейминге проблемы (Problem Framing Note)
## Задача: CHG-20260502-02 — Подготовка проекта к релизу и SEO-оптимизация

### 1. Источник задачи (Brief Origin Gate)
* **Кто сформулировал:** max (владелец проекта).
* **Откуда пришла задача:** Бизнес-требование по запуску готового локального сайта в публичный доступ и подготовке его к индексации поисковиками.
* **Первичный сигнал:** Цель (Goal) — превратить локальный макет в живой инструмент для привлечения клиентов.
* **Надежность источника:** Абсолютная (прямое указание владельца проекта).

### 2. Суть проблемы и предлагаемые изменения
* **Формулировка проблемы:** Сайт визуально готов, но его код содержит тестовые контакты, отсутствуют файлы метаданных для поисковых роботов (OpenGraph, Robots, Sitemap), и он не настроен для сборки и развертывания на хостинге.
* **Предлагаемое решение:**
  1. Прописать боевые метатеги (OpenGraph, Title, Description) в `index.html`.
  2. Заменить тестовые контакты в `src/utils.js` на реальные ссылки Виктора (WhatsApp, Telegram, Instagram).
  3. Создать файлы `robots.txt` и `sitemap.xml` в папке `public/`.
  4. Подготовить конфигурацию деплоя (для поддержки SPA-роутинга React Router).
* **Что не должно сломаться:** Премиальный дизайн (Derzayn UI), загрузка шрифтов/ассетов и переходы по страницам через роутер.

### 3. Оценка ключевых рисков (Сокращенный Six Hats Review)
1. **Риск роутинга SPA (Критический):** Так как сайт использует React Router (`react-router-dom`), при перезагрузке страниц (например, `/contacts`) на хостинге возникнет ошибка 404, если сервер не настроен перенаправлять все запросы на `index.html`. 
   * *Решение:* Добавить конфигурационный файл редиректов (например, `vercel.json` или `_redirects` в зависимости от хостинга) для перенаправления запросов.
2. **Риск блокировки индексации:** Ошибки в `robots.txt` могут заблокировать сайт от сканирования роботами Google/Яндекс.
   * *Решение:* Написать чистый `robots.txt` с разрешением индексации и ссылкой на `sitemap.xml`.
3. **Риск неработающих ссылок связи:** Ошибки в форматировании номеров телефонов в ссылках WhatsApp/Telegram приведут к потере заявок.
   * *Решение:* Тщательно проверить форматы ссылок (например, WhatsApp требует международный формат без плюсов: `https://wa.me/79...`).

### 4. Вердикт фрейминга (Framing Verdict)
* **Вердикт:** `ready_for_routing` (Проблема ясна, границы очерчены, риски определены).
* **Следующий шаг:** Переход к фазе `/route` для окончательного выбора хостинга (трека) и начала сборки.
