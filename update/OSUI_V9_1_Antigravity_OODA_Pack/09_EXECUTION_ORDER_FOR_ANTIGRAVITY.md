# Порядок подачи файлов в Antigravity

Используй этот порядок буквально.

## Шаг 1
Передай:
- `01_PHASE_1_OBSERVE_REPO_AUDIT.md`

Ожидаемый результат:
- audit file
- gap map
- список missing/weak files

## Шаг 2
Передай:
- `02_PHASE_2_ORIENT_MEMORY_AND_BASELINE.md`

Ожидаемый результат:
- memory files
- baseline templates
- capability registry

## Шаг 3
Передай:
- `03_PHASE_3_DECIDE_GATES_AND_ROUTING.md`

Ожидаемый результат:
- усиленный `route.md`
- усиленный `GEMINI.md`
- gate logic summary

## Шаг 4
Передай:
- `04_PHASE_4_ACT_CONTEXT_AND_ENHANCE.md`

Ожидаемый результат:
- новый `context.md`
- новый `enhance.md`
- context-loading sync

## Шаг 5
Передай:
- `05_PHASE_5_ACT_VERIFY_RELEASE_AND_TRACE.md`

Ожидаемый результат:
- новый `verify.md`
- новый `release.md`
- memory sync rules

## Шаг 6
Передай:
- `06_PHASE_6_ACT_HARDEN_SCRIPTS_AND_SANDBOX.md`

Ожидаемый результат:
- SANDBOX rule
- scripts minimum set
- capability update

## Шаг 7
Передай:
- `07_PHASE_7_PILOT_CHANGE_AND_RETRO.md`

Ожидаемый результат:
- один честный пилотный цикл
- retro report

## Шаг 8
Передай:
- `08_PHASE_8_FINAL_ACCEPTANCE.md`

Ожидаемый результат:
- финальный статус:
  - `migration_complete`
  - или `migration_partially_hardened`

## Главное правило
Никаких перепрыгиваний.  
Каждый следующий шаг допустим только после отчёта по предыдущему.
