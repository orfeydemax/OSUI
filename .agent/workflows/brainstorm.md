# /brainstorm — Creative Exploration

> V8 Reference: §10.4
> Lives under `/clay` and `/frame` — does NOT replace `/frame`

## Purpose

Expand options when a task is raw, contradictory, or has multiple valid approaches.

## When to Use
- During `/clay` when input is too vague for direct planning
- During `/frame` when contradiction seeds need exploration
- When owner requests divergent thinking before convergent decisions

## Rules
- `/brainstorm` does NOT substitute for `/frame`
- `/brainstorm` produces options — not decisions
- Decisions require human owner approval
- Results feed back into the change card (assumptions, contradictions, trade-offs)

## Steps

### 1. Define Brainstorm Scope
- What specific question or problem to explore?
- What constraints exist?
- What is the desired output format?

### 2. Generate Options
Use divergent techniques:
- Assumption reversal
- Analogy exploration
- Worst-case scenario analysis
- Constraint elimination
- Alternative architecture paths

### 3. Contradiction Analysis
For each option, identify:
- Internal contradictions
- Conflicts with existing system
- Feasibility constraints
- Risk profile

### 4. Synthesize Seeds
Output:
- Contradiction seeds
- Assumption seeds
- Trade-off seeds
- Track impact notes

### 5. Return to Caller
- If called from `/clay` → return with enriched draft
- If called from `/frame` → return with seeds for framing note

## Output
- Options list with pros/cons
- Contradiction seeds
- Assumption seeds
- Trade-off seeds
- Recommendation (non-binding — human decides)

## Context Budget
- **Class: Light to Medium** — read change card, relevant context, existing constraints
