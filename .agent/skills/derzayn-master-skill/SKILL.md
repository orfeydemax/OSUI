# Derzayn Master Skill: The Engineering of "Daring" Design

## 0. ACTIVE BASELINE CONFIGURATION

* **DESIGN_VARIANCE:** 8 (1 = Traditional symmetry/standard grids, 10 = High-agency asymmetry/experimental modules).
* **MOTION_INTENSITY:** 6 (1 = Simple hovers/static, 10 = Advanced scroll-triggers/cinematic physics).
* **VISUAL_DENSITY:** 4 (1 = Airy/Art Gallery spacing, 10 = Packed/Data-dense Cockpit UI).

> **AI Directive:** Adjust these values dynamically based on the project requirements. Use them as global variables to determine the complexity of the Swiss Grid and the depth of the Motion Engine.

## 1. THE DERZAYN CORE: 10-STEP WORKFLOW [MANDATORY]

Every project MUST follow this chronological pipeline for maximum marketing impact:

1. **[Briefing]** Full extraction of client goals, TA, and functional requirements.
2. **[Competitive War-Room]** Deep dive into rival structures to find visual and logical gaps.
3. **[Landing Structure]** The "Marketing Layer": Mapping the high-level logic before any design.
4. **[UX Skeleton]** Low-fidelity wireframe to validate the information flow.
5. **[Moodboard & Direction]** Selecting specific visual references and font pairings.
6. **[UX-Copywriting]** Content-first approach. Use concrete, conversion-driven copy.
7. **[Visual Concept]** Design 2-3 key blocks to establish the "Daring" (Дерзкий) aesthetic.
8. **[Full Interface Design]** Detailed design of all remaining blocks and pages.
9. **[UI-Kit & Componentry]** Create a robust, atomic design system for consistency.
10. **[Adaptation & Launch]** Mobile-first adaptation + final delivery (Tilda/Code).

## 2. THE SWISS GRID & COMPOSITION

Apply "International Typographic Style" to every layout:

* **Asymmetric Modular Grids:** Utilize CSS Grid with fractional units (e.g., `2fr 1fr`). Avoid centering; use negative space to create tension and focus.
* **Typography Hierarchy:** Massive headlines (`text-7xl+`) paired with tiny, precise metadata (`text-[10px] mono`).
* **Swiss Precision:** Every margin, gap, and padding must be a multiple of 4 or 8.
* **Scanning Control:** Design layouts to lead the eye via F and Z patterns to the CTA.

## 3. DESIGN ENGINEERING DIRECTIVES

* **Rule 1: Font Selection:** BANNED: `Inter`. REQUIRED: `Geist`, `Satoshi`, `Cabinet Grotesk`, or `Outfit`.
* **Rule 2: Color Strategy:** Saturation < 80%. No "AI Purple". Use Zinc/Slate bases with one high-contrast, emotional accent color (Deep Rose, Electric Blue, Emerald).
* **Rule 3: Card-Free Layouts:** Avoid boxes. Use `divide-y`, `border-t`, or spacing to group elements. The "3 cards in a row" pattern is BANNED.
* **Rule 4: Liquid Glass:** Transparent panels MUST have a 1px inner border and subtle inner shadow for edge refraction.

## 4. MOTION & INTERACTION ENGINE

* **Spring Physics:** ONLY. `type: "spring", stiffness: 100, damping: 20`. NO linear or ease-in transitions.
* **Magnetic Buttons:** Implement light cursor pull on all primary CTAs using `useMotionValue`.
* **Sequential Reveal:** All lists/grids must use `staggerChildren` for a "waterfall" load-in effect.
* **Tactile Feedback:** Apply `scale-[0.98]` on `:active` to simulate physical button press.

## 5. TECHNICAL GUARDRAILS

* **Viewport Fix:** Use `min-h-[100dvh]` exclusively. Never use `h-screen`.
* **Icon Library:** `@phosphor-icons/react` is the only allowed library. Default `strokeWidth` to `1.5`.
* **No Emojis:** Strictly BANNED. Use clean SVG primitives.
* **Mobile-First Shift:** Asymmetric desktop layouts must collapse into a clean, single-column `px-4` layout on screens < 768px.
